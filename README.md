# Tenant Management App

Android application developed for **Post Lab 3 & Individual Labs**.

## 📱 Project Overview
The Tenant Management App is designed to streamline tenant tracking, property management, and administrative workflows on Android.

## 📂 Project Structure
- **`app/`**: Contains the core application source code (`src/main/java/...`), UI layouts (`src/main/res/layout/...`), resources, and Android manifest.
- **`gradle/`**: Gradle wrapper and build tool configurations.

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/NaadirRana/NAADIRMADEV.git
   ```
2. Open the project in **Android Studio**.
3. Allow Gradle to sync dependencies.
4. Run the app on an emulator or connected Android device.
